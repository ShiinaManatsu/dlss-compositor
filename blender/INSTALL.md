# Installing DLSS Compositor Blender Extension (v2)

## Requirements
- Blender 5.1+

## Development Install
1. Open Blender
2. Edit > Preferences > Extensions
3. Click the dropdown ▼ in top right > Install from Disk
4. Select this directory (dlss_compositor/) or a zip of it
5. Enable "DLSS Compositor" in the extensions list

## Verify Install
Open Render Properties — you should see "DLSS Compositor" panel.
