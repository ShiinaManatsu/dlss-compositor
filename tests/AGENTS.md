**Integration:**

## CONVENTIONS

- **One file per module**: `test_<module>.cpp` maps to `src/.../<module>.cpp`.
- **Test names are full sentences**: `TEST_CASE("ExrReader loads reference 64x64 EXR with all expected channels", "[exr][requires_fixture]")`.
- **`REQUIRE`** halts on failure; **`CHECK`** continues after fail. Use `REQUIRE` for preconditions, `CHECK` for value assertions.
- **GPU gate pattern**: Vulkan init in fixture; `SKIP()` if NGX unavailable (`tests/test_sequence_processor.cpp:38-39`).
- **Fixture paths**: relative to build dir via `std::filesystem::current_path()` (`tests/test_exr_reader.cpp:10,21`).
- **Binary target name**: `dlss-compositor-tests` (not `dlss_tests`).
- **No mocks** — integration-leaning test style; real NGX API calls when GPU available.
- **Fixtures are committed** — `tests/fixtures/.gitkeep` ensures directory; EXR files are 64×64 for fast CI.

## ADDING A NEW TEST

1. Create `tests/test_<module>.cpp`
2. Add to `tests/CMakeLists.txt` `target_sources(dlss-compositor-tests PRIVATE test_<module>.cpp)` (line 2-18 pattern)
3. Place fixtures in `tests/fixtures/`; CMake auto-discovers tests via `catch_discover_tests`
4. Tag: `[unit]` for CPU-only, `[gpu]` if Vulkan init required, `[integration]` for full pipeline
5. Optional: add named CTest with `SKIP_REGULAR_EXPRESSION` for GPU tests (pattern at `tests/CMakeLists.txt:34-41`)
6. Run: `ctest --test-dir build --config Release -R <module>`

## ANTI-PATTERNS

- ❌ **Don't fail hard on missing GPU** — use `SKIP()` so CI runs CPU tests without RTX.
- ❌ **Don't hardcode absolute paths** — use `std::filesystem::current_path()` relative lookups (see `test_exr_reader.cpp:10`).
- ❌ **Don't load large real EXR files in unit tests** — fixtures are 64×64 for fast CI.
- ❌ **Don't skip fixture files in commits** — tests break without them. Fixtures are committed to repo.
