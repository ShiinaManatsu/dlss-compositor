DESIGN DECISIONS
----------------
- LDR mode: sRGB EOTF only (no tonemap). Per user decision round 2.
  Values outside [0,1] are clamped. This is correct for SDR content.
- HDR mode: ACES Filmic (Narkowicz approx.) followed by PQ ST.2084.
  ACES first compresses highlights from [0,∞) to [0,1].
  PQ then encodes 100-nit reference correctly.
  Skipping ACES on HDR path would burn out extreme highlights.
- Blender convention: 1.0 scene-linear = 100 nits diffuse white.
  PQ input normalization: L = linear * 0.01 = nits / 10000.
- This pass is called ONLY in FG pipeline.
  SR-only path skips entirely (no TonemapPass::execute call).

REFERENCES
