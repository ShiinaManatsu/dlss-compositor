Task 5: Unify Blender jitter calculation
=========================================

Goal: apply_jitter() is the single source of truth; export_camera reads from _runtime_jitter dict.

Changes made to both files:
  - blender/dlss_compositor_aov/__init__.py
  - blender/aov_export_preset.py

1. Added module-level `_runtime_jitter: dict = {}` (near existing global state)
2. save_original_shift() now clears `_runtime_jitter` via `_runtime_jitter.clear()` at render init
3. apply_jitter() stores `_runtime_jitter[frame_num] = (jitter_x, jitter_y)` after computing
4. export_camera.execute() reads from `_runtime_jitter[frame_num]` when available,
   falls back to Halton re-computation otherwise
