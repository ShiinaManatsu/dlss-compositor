Task 1 — Blender exporter switch to standard EXR + new panel controls
======================================================================

Date: 2026-05-15
Branch: opus-rework
Plan ref: .sisyphus/plans/gui-rewrite.md#Task1

SUMMARY OF CHANGES
------------------

Two files modified:

1. blender/dlss_compositor_aov/__init__.py   (extension entry point)
2. blender/aov_export_preset.py              (legacy standalone duplicate)

Both files now share the same compositor configuration logic; the standalone
script also carries a bl_info dict (bumped to (0, 2, 0)) so it can be
loaded outside the extension manifest path.


CHANGE LIST (per file)
----------------------

blender/dlss_compositor_aov/__init__.py
  * Added globals near existing jitter state:
        _original_resolution_x = 0
        _original_resolution_y = 0
  * Added two new persistent handlers:
        apply_render_scale(scene)     -> scales render.resolution_{x,y}
                                         by Scene.dlss_compositor_render_scale
                                         on render_init (when scale != 1.0)
        restore_render_scale(scene)   -> restores original resolution on
                                         render_complete / render_cancel
  * DLSSCOMP_OT_configure_passes.execute() — replaced the entire single
    OPEN_EXR_MULTILAYER File Output node setup (lines 219-301 in the old
    file) with a dual standard-OPEN_EXR setup:
        - "DLSS_Main" CompositorNodeOutputFile
            * format.file_format = "OPEN_EXR"
            * format.color_depth = "32"
            * format.exr_codec   = Scene.dlss_compositor_compression
            * Two slots:
                "Image" (slot.path = "####")        <- Render Layers Image
                "Depth" (slot.path = "####.depth")  <- Render Layers Depth
        - "DLSS_VectorSplit" CompositorNodeSeparateXYZ
            * splits Render Layers Vector pass into X/Y/Z
        - "DLSS_VectorPack"  CompositorNodeCombineColor (mode=RGB)
            * R = SeparateXYZ.X, G = SeparateXYZ.Y, B = 0
        - "DLSS_MV" CompositorNodeOutputFile
            * format.file_format = "OPEN_EXR"
            * format.color_depth = "32"
            * format.exr_codec   = "ZIP"  (lossless, motion vectors are
                                           precision-critical)
            * One slot, slot.path = "####.mv"  <- CombineColor Image
    Resulting per-frame layout in <output_dir>:
        <output_dir>/0001.exr        -> Combined RGBA
        <output_dir>/0001.depth.exr  -> single-channel Z
        <output_dir>/0001.mv.exr     -> RG packed motion vectors
    The .mv.exr is the sibling file the C++ pipeline (T2 mergeMvFile)
    expects via the "<stem>.mv.exr" naming convention.
  * DLSSCOMP_PT_export_panel.draw() — added two new controls and a
    format-info label, immediately around the "Configure All Passes"
    button:
        layout.prop(scene, "dlss_compositor_compression",
                    text="EXR Compression")
        layout.prop(scene, "dlss_compositor_render_scale",
                    text="Render Scale", slider=True)
        layout.operator(... "Configure All Passes" ...)
        layout.label(text="Standard EXR (opens in RenderDoc)", icon="INFO")
  * register() — added two new Scene properties and registered the new
    handlers:
        Scene.dlss_compositor_compression: EnumProperty
            items: NONE / ZIP / ZIPS / PIZ / DWAA / DWAB
            default: ZIP
        Scene.dlss_compositor_render_scale: FloatProperty
            range 0.1..2.0, default 1.0, subtype FACTOR
        bpy.app.handlers.render_init.append(apply_render_scale)
        bpy.app.handlers.render_complete.append(restore_render_scale)
        bpy.app.handlers.render_cancel.append(restore_render_scale)
  * unregister() — symmetric cleanup for the two new properties and
    handlers.

blender/aov_export_preset.py
  * File regenerated to mirror the new __init__.py (same handlers,
    operator body, panel and registration code).
  * bl_info dict added/preserved at top with version bumped to (0, 2, 0)
    per task requirement.
  * Note: this duplicate exists for headless `--python aov_export_preset.py`
    invocation. The blender/dlss_compositor_aov/blender_manifest.toml
    version is currently 0.3.0; it is left untouched because it is
    already higher than the requested 0.2.0 bump and is the source of
    truth for the installed extension. See "VERSION DISCREPANCY" below.


REMOVED CODE PATHS
------------------
* `OPEN_EXR_MULTILAYER` references — deleted from both files.
* `file_output.format.quality = 95`              — irrelevant for OPEN_EXR.
* `file_output.file_name = "aov_"`               — non-existent attribute,
                                                  legacy bug.
* In aov_export_preset.py, the `bpy.app.version >= (5, 0, 0)` branching
  for the compositor tree / slot collection / pass-name picking was
  collapsed because the new dual-output path uses the modern
  CompositorNodeOutputFile.file_slots API everywhere (consistent with
  the extension entry point that already targets Blender 5.0+).


NEW SCENE PROPERTIES (UI-bound)
-------------------------------
Scene.dlss_compositor_compression  EnumProperty (default 'ZIP')
Scene.dlss_compositor_render_scale FloatProperty (default 1.0, 0.1..2.0)
