=== WHY VISUAL QUALITY IS UNAFFECTED ===

Three independent sources confirm GBuffer inputs are optional for DLSS-SR:

1. NVIDIA NGX SDK header nvsdk_ngx_helpers_vk.h explicitly states GBuffer
   inputs are "OPTIONAL — only for research purposes."

2. Streamline SDK documentation does not list GBuffer as a required input
   for NVSDK_NGX_DLSS_Feature. Required: Color, Depth, MotionVectors, Output.
   Optional (Streamline): Exposure, Jitter_Offset_X, Jitter_Offset_Y.

3. vk_streamline sample code only tags 4 resources:
   - Color
   - Depth
   - MotionVectors
   - Output

The removed code path was already a no-op (or near-no-op):
  - GlossCol was never uploaded to GPU (empty buffer)
  - DiffCol/Normal/Roughness were uploaded but NGX evaluation ignored them
  - pInAttrib's GBuffer enabling flags were already set to false
