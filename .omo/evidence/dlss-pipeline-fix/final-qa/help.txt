dlss-compositor v0.2.1
Usage: dlss-compositor [options]
Options:
  --input-dir <dir>      Input EXR sequence directory
  --output-dir <dir>     Output EXR sequence directory
  --scale <factor>       Upscale factor (float, 1.0–8.0; default 2.0). Can combine with --interpolate.
  --interpolate <mode>   Frame interpolation (2x or 4x; requires --camera-data). Can combine with --scale.
  --camera-data <file>   Camera metadata JSON file
  --memory-budget <GB>   GPU memory budget for texture pool (default: 8, min: 1)
  --quality <mode>       DLSS quality mode (DLAA|MaxQuality|Balanced|Performance|UltraPerformance)
  --preset <mode>        SR preset hint (auto|J|K|L|M; default: auto, NVIDIA-recommended per quality)
  --preset-dlaa <mode>   SR preset for DLAA (auto|J|K|L|M)
  --preset-quality <mode> SR preset for MaxQuality (auto|J|K|L|M)
  --preset-balanced <mode> SR preset for Balanced (auto|J|K|L|M)
  --preset-performance <mode> SR preset for Performance (auto|J|K|L|M)
  --preset-ultra-performance <mode> SR preset for UltraPerformance (auto|J|K|L|M)
  --preset-ultra-quality <mode> SR preset for UltraQuality hint slot (auto|J|K|L|M)
  --channel-map <file>   Custom channel name mapping JSON file
  --encode-video [file]  Encode output sequence to MP4 via FFmpeg
  --fps <rate>           Video encoding frame rate (default: 24)
  --source-fps <rate>    Source footage frame rate for DLSS frame timing (default: 30)
  --exr-compression <m>  EXR compression (none|zip|zips|piz|dwaa|dwab)
  --exr-dwa-quality <f>  DWA compression quality (default: 95)
  --sharpness <0.0..1.0> Post-DLSS sharpening (default 0.0 = off, recommended 0.2-0.4)
  --output-passes <list> Output passes (comma-separated: beauty,depth,normals; default: beauty)
  --tonemap <mode>       FG transport encoding (none|pq|custom; default: pq)
  --no-inverse-tonemap   Skip inverse PQ decode on FG output (output stays PQ-encoded)
  --tonemap-lut <file>   Custom forward LUT binary (implies --tonemap custom)
  --inverse-tonemap-lut <file>  Custom inverse LUT binary
  --ngx-log-level <level> NGX log verbosity (off|error|warn|info|verbose; default: off)
  --progress-format <fmt> Progress reporting format (human|json; default: human)
                          'json' emits NDJSON events to stdout (one JSON object per line)

Advanced NGX settings (power-user; defaults match prior hardcoded behavior):
  --feature-flag-hdr / --no-feature-flag-hdr               HDR feature flag (default: enabled)
  --feature-flag-mv-low-res / --no-feature-flag-mv-low-res Render-resolution motion vectors (default: enabled)
  --feature-flag-auto-exposure / --no-feature-flag-auto-exposure  NGX auto-exposure (default: enabled)
  --enable-output-subrects / --no-enable-output-subrects   Output subrect support (default: disabled)
  --exposure-scale <float>      InExposureScale; (0.0, 100.0] (default: 1.0)
  --frame-time-delta-ms <float> Override frame time delta in ms; > 0.0 (default: auto from --source-fps)
  --dlss-sharpness <0.0..1.0>   NGX InSharpness (default: 0.0 = off)
  --enable-dynamic-resolution / --no-enable-dynamic-resolution  Reserved knob (default: disabled)
  --no-camera-cut-detection               Disable camera cut detection (default: enabled)
  --camera-cut-translation-threshold <f>  World-unit translation threshold for cut detection (default: 5.0)
  --camera-cut-rotation-threshold <f>     Rotation threshold in degrees for cut detection (default: 30.0)

  --test-ngx             Test NGX/DLSS-SR availability and exit
  --test-vulkan         Initialize Vulkan compute context and exit
  --help, -h             Show this help
  --version              Show version
