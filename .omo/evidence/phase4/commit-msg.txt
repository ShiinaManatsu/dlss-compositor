feat(cli): add --progress-format json with NDJSON event stream

New --progress-format <human|json> CLI flag (default: human, fully
backward compatible). When json is set, sequence_processor emits one
newline-delimited JSON object per progress event to stdout: started,
frame_started, frame_written, error, complete. Stdout is reserved
exclusively for NDJSON; Log::info console mirror is rerouted to stderr
via the new Log::setQuietStdout() toggle so NGX/Vulkan info logs do not
pollute the event stream.

Adds NdjsonEmitter (mutex-guarded fwrite + newline + fflush, global
singleton) and 5 new Catch2 unit tests covering default state, toggle,
no-op-when-disabled, thread safety, and singleton identity.
