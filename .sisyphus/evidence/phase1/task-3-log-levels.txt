  5. src/main.cpp              — Pass config.ngxLogLevel to both ngx.init() calls

NGX SDK enum (nvsdk_ngx_defs.h):
  OFF=0, ON=1, VERBOSE=2, NUM=3

Log level mapping (our int → NGX enum):
  0 (off)     → OFF
  1 (error)   → ON   (no ERROR-only level exists)
  2 (warn)    → ON   (default)
  3 (info)    → ON   (no INFO level exists)
  4 (verbose) → VERBOSE

Default behavior change: VERBOSE → ON (warn), much quieter by default.
