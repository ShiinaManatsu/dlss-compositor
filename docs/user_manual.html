第一章：什么是 DLSS Compositor？

DLSS Compositor v2 是一个将 Blender Cycles 离线渲染序列通过 NVIDIA DLSS 超分辨率（SR）和帧生成（FG）处理的开源工具。它读取 Blender 渲染的多通道 EXR 序列，在 GPU 上使用 DLSS AI 提升画质和帧率，输出场景线性 EXR 或 16 位 PNG 序列。

整个系统由三层组成：

  • Blender 扩展：配置渲染通道、自动导出相机数据（静默进行）
  • Flutter GUI：任务配置、实时预览、进度监控
  • C++ 引擎：Vulkan + NGX 驱动的 SR+FG 管线，负责实际处理和输出
ℹ️ v2 仅支持 Vulkan 输出。不支持 DirectX 12。GPU 界面为 Flutter on Windows，不是 Electron。

第二章：快速开始

前提条件

  • NVIDIA RTX GPU（SR 需要 RTX 20 以上；FG 需要 RTX 40 以上）
  • NVIDIA 驱动 535 或更新版本
  • Blender 5.1 或更新版本
  • Windows 10/11（64位）

五步流程

  1. 安装 Blender 扩展：打开 Blender → 编辑 → 首选项 → 扩展 → 从本地安装 blender-plugin/dlss_compositor/
  2. 在 Blender 中打开你的场景，在 N 面板找到 DLSS Compositor 选项卡
  3. 设置输出分辨率 → 选择质量模式 → 点击 Apply Settings → 渲染动画（Ctrl+F12）
  4. 渲染完成后，EXR 序列与 dlssconfig.json 已自动生成
  5. 启动 dlss_compositor_gui.exe → 打开 dlssconfig.json → 配置参数 → 点击 Start
ℹ️ 每次修改 Blender 场景中影响分辨率或质量模式的设置后，需要重新点击 Apply Settings。

第三章：工作流程

完整数据流如下：

Blender 渲染（EXR 序列 + 运动矢量 + 深度）
         ↓
  dlssconfig.json（Schema 单一来源）
         ↓
  dlss-compositor-cli.exe（C++ 引擎）
     ├── DLSS SR（场景线性输入，调色前）
     ├── Tonemap（ACES Filmic + PQ ST.2084）
     └── DLSS FG（调色后，显示就绪输入）
         ↓
  输出：EXR（场景线性）/ PNG（16 位，LDR）
层次组件职责

管线顺序

这个顺序是 DLSS SDK 规定的，不能改变：

  1. SR 输入必须为场景线性（EOTF 尚未应用）
  2. 调色（Tonemap）在 SR 之后进行
  3. FG 输入必须为显示就绪（调色 + EOTF 之后）

第五章：注意事项（Gotchas）

⚠️ Gotcha 1：质量模式与分辨率强绑定
质量模式决定了 resolution_percentage、Jitter 序列长度和相位数。渲染期间或渲染后修改质量模式，需要完全重渲所有帧。已渲染的帧与新设置不匹配，会导致 SR 输出退化、时序抖动。
⚠️ Gotcha 2：Cycles 降噪必须开启
DLSS SR 依赖降噪后的干净帧。Apply Settings 会自动强制开启 Cycles 降噪，请勿手动关闭。未降噪的含噪 EXR 会让 SR 的 AI 推断出错误的时序信息。
⚠️ Gotcha 3：OCIO 必须保持 Raw
File Output 节点的 color_management 必须是 OVERRIDE 且 view_transform = Raw，才能输出未编码的场景线性 EXR。如果在 Apply Settings 之后手动修改了这些设置，需重新点击 Apply Settings。
⚠️ Gotcha 4：HDR 项目需要正确的显示设备
在 Blender 颜色管理中将 Display Device 设为 Rec.2100-PQ 或 Rec.2100-HLG，is_hdr 标志将自动推导为 true。HDR 管线使用 ACES Filmic + PQ ST.2084，输出完整的 HDR 范围。不存在"10 nit 裁剪"——这是 v1 的错误说法。
⚠️ Gotcha 5：不需要手动导出相机数据
v2 在渲染期间静默地自动导出相机矩阵和运动矢量数据，不需要单独的导出步骤。如果你在 GUI 中看到"相机数据缺失"错误，说明渲染时扩展未正确加载。
⚠️ Gotcha 6：运动矢量映射规则
DLSS 坐标系要求：DLSS_MV = (Blender.X, -Blender.Y)。只有 Y 轴取反，X 轴直接传入（两次符号翻转相互抵消）。不要用 -blenderMv（整体取反）——这是 v1 的隐藏 bug。
⚠️ Gotcha 7：InReset 仅用于首帧/跳帧/镜头切换
InReset = true 只能在以下三种情况下设置：第一帧、序列中存在帧间隔、或摄像机发生不连续跳切。绝对不要每帧都设置为 true——这会清空时序历史，完全抵消 DLSS 的效果。

第六章：常见问题 FAQ

"NGX feature unavailable" 错误
将 NVIDIA 驱动更新到 535+ 版本。RTX 30 系列及更早的 GPU 不支持帧生成（FG）。
"dlssconfig schema invalid" 错误
确保 Blender 扩展已启用，然后重新渲染。错误信息中会指出具体的非法字段名称。
FG 倍率按钮显示为灰色
当前 GPU 不支持该倍率选项。RTX 40 系列（Ada 架构）支持最高 4×；RTX 30 系列不支持 FG。
输出的 EXR 颜色看起来不正确
检查 Blender 中的 OCIO 设置是否被修改为非 Raw。重新点击 Apply Settings 后再次渲染。
GUI 预览帧不更新
查看 GUI 底部日志面板中的错误信息。FFmpeg 报错或引擎崩溃都可能导致预览停止。
渲染速度比预期慢很多
确认已选择正确的质量模式（例如 Ultra Performance 用于草稿），并检查 GPU 是否被其他应用程序占用。
输出文件大小异常
EXR（16 位半精度）是预期的大文件格式。LDR 项目如果需要更小的文件，可以选择 PNG。

第七章：故障排查

自检命令

在命令行运行自检，它会验证 NGX 状态、Vulkan 设备能力和 FFmpeg 可用性：

dlss-compositor-cli.exe --self-check

日志文件

所有诊断信息写入 dlss-compositor.log（与 exe 文件同目录）。日志使用轮转文件策略，最大 10MB × 3 个文件。

ℹ️ stdout 仅用于 JSON-RPC 协议帧（GUI 通信）。诊断输出只在日志文件和 stderr 中。不要将 stdout 重定向到文件——这会破坏 GUI 通信。

Chapter 1: What is DLSS Compositor?

DLSS Compositor v2 processes offline Blender Cycles renders through NVIDIA DLSS Super Resolution (SR) and Frame Generation (FG). It reads multi-channel EXR sequences from Blender, upscales and/or interpolates frames using DLSS AI on your GPU, then outputs scene-linear EXR or 16-bit PNG sequences.

The system has three layers:

  • Blender extension: configures render passes, exports camera data silently during render
  • Flutter GUI: task configuration, live preview, progress monitoring
  • C++ engine: Vulkan + NGX SR+FG pipeline, handles processing and output
ℹ️ v2 supports Vulkan output only. DirectX 12 is not supported. The GUI is Flutter on Windows, not Electron.

Chapter 2: Quick Start

Prerequisites

  • NVIDIA RTX GPU (SR requires RTX 20 series or newer; FG requires RTX 40 series)
  • NVIDIA driver 535 or newer
  • Blender 5.1 or newer
  • Windows 10/11 (64-bit)

Five-step workflow

  1. Install the Blender extension: Edit → Preferences → Extensions → Install from Local → select blender-plugin/dlss_compositor/
  2. Open your scene in Blender, find the DLSS Compositor tab in the N panel
  3. Set output resolution → pick a quality mode → click Apply Settings → render animation (Ctrl+F12)
  4. After render: EXR sequences and dlssconfig.json are generated automatically
  5. Launch dlss_compositor_gui.exe → open dlssconfig.json → configure → click Start
ℹ️ Re-click Apply Settings after any change to resolution or quality mode in your Blender scene.

Chapter 5: Notes & Gotchas

⚠️ Gotcha 1: Quality mode and resolution are locked together
Quality mode determines resolution_percentage, jitter sequence length, and phase count. Changing quality mode after rendering requires a full re-render of all frames. Mismatched frames cause degraded SR output and temporal artifacts.
⚠️ Gotcha 2: Cycles denoising must be ON
DLSS SR relies on clean, denoised frames. Apply Settings forces Cycles denoising on. Don't disable it manually. Noisy EXR input causes DLSS to infer incorrect temporal information.
⚠️ Gotcha 3: OCIO must stay at Raw
File Output nodes require color_management = OVERRIDE and view_transform = Raw to produce unclamped scene-linear EXR. If you change this after Apply Settings, re-click Apply Settings before rendering.
⚠️ Gotcha 4: HDR projects need the correct display device
Set Blender's Display Device to Rec.2100-PQ or Rec.2100-HLG for HDR. The is_hdr flag is auto-derived from this setting. The HDR pipeline uses ACES Filmic + PQ ST.2084, preserving full range. There is no "10-nit clamp" — that was a v1 bug.
⚠️ Gotcha 5: No manual camera export step
v2 exports camera matrices and motion vector data silently during render. There's no separate "Export Camera Data" button. If the GUI reports missing camera data, the extension wasn't loaded correctly when you rendered.
⚠️ Gotcha 6: Motion vector mapping
DLSS coordinate convention requires: DLSS_MV = (Blender.X, -Blender.Y). Only Y is negated — X passes through (two sign flips cancel). Don't apply -blenderMv as a whole-vector negation; that was a hidden v1 bug masked by a wrong InMVScale value.
⚠️ Gotcha 7: InReset on first frame and cuts only
Set InReset = true only on: the first frame, a frame gap in the sequence, or a camera discontinuity (cut). Never set it every frame — that destroys temporal history and eliminates DLSS's entire benefit.

Chapter 6: FAQ

"NGX feature unavailable"
Update NVIDIA drivers to 535 or newer. RTX 30 series and earlier GPUs don't support Frame Generation.
"dlssconfig schema invalid"
Make sure the Blender extension is enabled, then re-render. The error message names the specific invalid field.
FG multiplier buttons are grayed out
Your GPU doesn't support that multiplier. RTX 40 series (Ada architecture) supports up to 4×. RTX 30 series doesn't support FG at all.
Output EXR has wrong colors
The OCIO setting in Blender was changed after Apply Settings. Set it back to Raw and re-click Apply Settings, then re-render.
GUI preview frame not updating
Check the log panel at the bottom of the GUI for error messages. FFmpeg errors or engine crashes both prevent preview updates.
Render is much slower than expected
Confirm you've selected the right quality mode for your task (Ultra Performance for drafts). Check whether another application is competing for the GPU.
Output files are very large
EXR (16-bit half-float) is inherently large. For LDR projects, choose PNG for more compact output.

Chapter 7: Troubleshooting

Self-check command

Run the self-check from a terminal to validate NGX status, Vulkan device capabilities, and FFmpeg availability:

dlss-compositor-cli.exe --self-check

Log file

All diagnostics go to dlss-compositor.log in the same directory as the exe. Logs rotate at 10 MB with 3 retained files.

ℹ️ stdout is reserved exclusively for the JSON-RPC Content-Length protocol (GUI communication). Diagnostic output only appears in the log file and stderr. Don't redirect stdout to a file — it breaks GUI communication.

# DLSS Compositor v2 User Manual — Embedded Reference

## What It Does
Processes Blender Cycles EXR renders through NVIDIA DLSS SR (upscaling) and FG (frame generation).
Three-layer architecture: Blender extension + Flutter GUI + C++ Vulkan/NGX engine.
Output: Vulkan only. No DirectX 12. GUI is Flutter on Windows, not Electron.

## Quality Modes (DLSS SR §3.7.1.1)
| Mode             | Scale  | Render % | Jitter Phases |
|------------------|--------|----------|---------------|
| DLAA             | 1×     | 100%     | 8             |
| Quality          | 1.5×   | 67%      | 18            |
| Balanced         | 1.724× | 58%      | 24            |
| Performance      | 2×     | 50%      | 32            |
| UltraPerformance | 3×     | 33%      | 72            |

Jitter: Halton sequence, radix 2 (X), radix 3 (Y).
"base=8" = minimum phase count for DLAA/UQ. NOT the Halton radix.

## Frame Generation Multipliers
- 2×, 3×, 4× — RTX 40 series (Ada) only
- RTX 30 series: FG not supported

## Pipeline Order (mandatory)
1. SR input: scene-linear (no EOTF)
2. Tonemap: ACES Filmic + PQ ST.2084
3. FG input: display-ready (after tonemap + EOTF)

## Output Formats (v2)
- EXR (16-bit half-float, scene-linear)
- PNG (16-bit)

NOT in v2 (enum placeholders only, not registered):
- DNxHR, H.264, H.265, AV1, AVIF, JPEG, WebP

## Key Gotchas (7 items)
1. Quality mode + resolution locked — changing requires full re-render
2. Cycles denoising must be ON (Apply Settings forces this)
3. OCIO must be Raw (Apply Settings forces this)
4. HDR: use Rec.2100-PQ display device → is_hdr=true auto-derived
5. Camera export is automatic — no separate export step in v2
6. MV mapping: DLSS_MV = (Blender.X, -Blender.Y) — Y only negated
7. InReset = true on first frame / frame gap / camera cut ONLY — never every frame

## DLSS Technical Facts (no myths)
- FG uses ACES Filmic + PQ ST.2084 — full HDR range, NO "10-nit clamp"
- SR before tonemap (scene-linear input) — §3.1
- FG after tonemap (display-ready input) — FG §HDR
- InMVScaleX = InMVScaleY = 1.0 — MVs in pixel units (§3.6.3)
- stdout is JSON-RPC only — diagnostics to spdlog stderr + rotating file

cli/src/core/dlssconfig.schema.json is the single source of truth.
Do NOT copy it to cli/ or gui/assets/ — reference via relative path.
