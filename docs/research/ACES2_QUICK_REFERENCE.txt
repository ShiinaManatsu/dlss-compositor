=== CRITICAL CODE: ST.2084 (PQ) ENCODING ===

GLSL/Vulkan Version:
  vec3 LinearToPQ(vec3 lin, float peakNits) {
    const float m1 = 0.1593017578125;
    const float m2 = 0.0068408203125;
    const float c1 = 0.8359375;
    const float c2 = 0.58984375;
    const float c3 = 0.58447265625;
    
    vec3 norm = lin * (peakNits / 10000.0);
    vec3 V = pow(norm, vec3(m1));
    vec3 Lp = (c1 + c2 * V) / (1.0 + c3 * V);
    return pow(Lp, vec3(m2));
  }

Inverse PQ (for decoding):
  V_inv = pow(pqValue, m2_inv)
  V = pow(max(V_inv - c1, 0) / (c2 - c3 * V_inv), m1_inv)
  linear = V * ref_white_nits / peakNits
